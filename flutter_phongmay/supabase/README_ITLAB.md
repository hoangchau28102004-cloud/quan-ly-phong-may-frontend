# IT Lab Room Management System

This folder contains the Supabase database schema and initial data used by the admin UI. It is copied from the web admin project and includes the table definitions, RLS policies and initial inserts.

Files:
- `migrations/20260604064320_create_it_lab_room_schema.sql` — full schema and RLS policies
- `migrations/20260604064334_insert_initial_data.sql` — base roles and sample session data

To apply these to a Supabase project, use the Supabase SQL editor or your migration tooling.
